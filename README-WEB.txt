SB2 TRANSFORMATIONS TOOL v1.9.4 - WEB VERSION (Android, iPhone/iPad, any PC)
=============================================================================

[EN] English
What it is
The "web" folder is the browser version of the tool: it runs in the phone browser
(Chrome, Firefox, Samsung Internet, Edge) with nothing to install. Everything happens on the device:
the ISO is never uploaded anywhere. It must be published on an HTTPS site
(browsers allow saving large files only from secure pages).

Publishing it for free with GitHub Pages (once, about 5 minutes):
 1. On github.com create a public repository, for example "sb2-transformations".
 2. "Add file" > "Upload files": drag the 6 files of the web folder
    (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png) and confirm (Commit).
 3. Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)" > Save.
 4. After 1-2 minutes the page is online at  https://YOURNAME.github.io/sb2-transformations/
    That link is the one to give to the players.

For Android players:
 1. Open the link in the browser.
 2. "Choose ISO…" > pick your original ISO.
 3. Set the options > "Create ISO".
 4. Tap "Save the new ISO": the file goes to the Download folder.
 5. Open it with PPSSPP.
About 2x the ISO size of free space is needed while creating it (temporary copy + final file);
the temporary copy is deleted with its button after the download, or at the next visit.
Optional: from the browser menu, "Add to Home screen" / "Install app" to have it like an app
(it also works offline after the first visit).
Online / ad hoc: the "Online code" and the "Settings code" (section 7) work as in the PC program, see ONLINE.txt.

[IT] Italiano
Cos'è
La cartella "web" contiene il tool in versione pagina web: funziona nel browser del telefono
(Chrome, Firefox, Samsung Internet, Edge) senza installare niente. Tutto avviene sul dispositivo:
l'ISO non viene mai caricata su internet. Deve però essere pubblicata su un sito HTTPS
(il browser permette di salvare file grandi solo da pagine sicure).

Come pubblicarla gratis con GitHub Pages (una volta sola, ~5 minuti):
 1. Su github.com crea un repository pubblico, per esempio "sb2-transformations".
 2. "Add file" > "Upload files": trascina i 6 file della cartella web
    (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png) e conferma (Commit).
 3. Settings > Pages > Source: "Deploy from a branch", branch "main", cartella "/ (root)" > Save.
 4. Dopo 1-2 minuti la pagina è online su  https://TUONOME.github.io/sb2-transformations/
    Quel link è quello da dare ai giocatori.

Per il giocatore Android:
 1. Apre il link nel browser.
 2. "Scegli ISO…" > sceglie la sua ISO originale.
 3. Imposta le opzioni > "Crea ISO".
 4. Tocca "Salva la nuova ISO": il file va nella cartella Download.
 5. La apre con PPSSPP.
Serve spazio libero pari a circa 2 volte l'ISO durante la creazione (copia temporanea + file finale);
la copia temporanea si cancella col pulsante dopo il download o alla visita successiva.
Facoltativo: dal menu del browser "Aggiungi a schermata Home" / "Installa app" per averla come un'app
(funziona anche offline dopo la prima apertura).
Gioco online / ad hoc: il "Codice online" e il "Codice impostazioni" (sezione 7) funzionano come nel programma per PC: vedi ONLINE.txt.
